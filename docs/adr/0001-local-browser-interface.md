# 以本機瀏覽器介面提供影片工作區

使用者在 2026-10-03 的設計訪談 Q1 選擇本機網頁：在自己的電腦啟動服務，
透過瀏覽器操作，影片下載與媒體處理在本機執行。這讓現有 Python 轉錄與媒體處理
流程可沿用，檔案也留在使用者電腦；代價是使用者需要啟動本機服務並提供處理資源。
字幕翻譯仍依需求呼叫 Gemini，因此本機介面不代表所有處理均離線。

本輪亦考慮過原生桌面程式與多人網站。改變運行型態會影響安裝、檔案存取及工作
執行邊界，因此記錄此決策；框架、進行中任務恢復與具體設定檔格式留待後續訪談。

Q16 於 2026-10-04 確認建立本機影片庫，自動保存影片、字幕版本及對話，跨次啟動
仍可開啟與續問，直到使用者手動刪除。這需要本機儲存與清理介面，換取重複學習
與舊引用可追溯；具體儲存技術、目錄及暫存預覽清理規則仍待設計。
