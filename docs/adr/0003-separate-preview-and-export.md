# 網頁預覽與下載成品分開處理

使用者於 2026-10-04 的設計訪談 Q14 確認：來源無法在瀏覽器直接播放時，另在本機
產生相容預覽，維持網頁內觀看、字幕切換與問答的流程。下載成品仍保留使用者選定
的畫質，預覽不可覆寫來源或替代成品。

這需要額外處理時間、磁碟空間與預覽生命週期管理，換取同一網頁內的觀看體驗。
預覽與成品必須有各自的用途及完成狀態；預覽轉換也必須保持字幕對應的時間軸。
預覽畫質、快取、取消與支援瀏覽器清單，仍由後續設計決定。

Q15 進一步確認成品保留來源影音串流，格式相容時優先 MP4，否則使用 MKV，並在
匯出前顯示實際格式。這接受成品副檔名可能不同，換取影音不必為固定格式重新壓縮；
字幕可依容器需求轉換。若封裝無法完成，應明確失敗，不以降畫質或預覽影片代替成品。

來源：[設計訪談 Q14、Q15](../design/youtube-workspace-interview.md)與
[官方相容性查證](../design/media-compatibility-notes.md)。

2026-10-04 修訂：燒錄字幕成品必須重新編碼，為本決策「成品不轉碼」的例外，見
[ADR 0004](0004-burned-in-subtitle-export.md)。可切換字幕軌成品仍依本決策 stream copy。
