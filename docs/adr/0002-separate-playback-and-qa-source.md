# 播放字幕與問答依據分開選擇

使用者在設計訪談 Q7 選擇由自己明確指定問答依據。切換播放器顯示的字幕語言，
或選用新匯入的字幕播放，都不自動改變問答來源；使用者可將匯入修正版明確設為
問答依據，以修正後的內容提問。

這保留了用修正版改善問答的能力，也避免翻譯差異與顯示語言切換使問答來源意外
改變。代價是介面需要呈現播放字幕與問答依據兩個選擇。若兩者共用一個選擇，日後
拆開會影響既有對話與引用的語意，因此記錄此邊界。

Q8 進一步確認每串對話固定使用同一份問答依據版本。使用者改用另一份依據時開新
對話，保留舊對話與對應字幕版本，舊引用仍定位到當時的原文與時間；新對話不帶入
舊依據所產生的回答。這需要保留版本與分開的對話，但可避免字幕修正後舊引用失真，
以及新回答沿用已被修正的資訊。Q16 已確認對話與來源版本跨重啟保存於本機影片庫，
刪除範圍與操作流程仍待設計。
