# 下載成品可選燒錄字幕並以硬體編碼重新輸出

使用者於 2026-10-04 的後續訪談推翻設計訪談 Q3「本次不提供固定燒錄」：貼入網址後
按一次「開始處理」即自動跑到下載成品，字幕形式可選**可切換字幕軌**或**燒錄字幕**，
預設燒錄。燒錄可選雙語字幕（目標語系在上、原文在下），樣式固定不提供調整。

燒錄必須重新編碼，因此 [ADR 0003](0003-separate-preview-and-export.md) 的
「成品保留來源影音串流」只適用可切換字幕軌成品。燒錄成品一律輸出 MP4
（H.264＋AAC），維持所選解析度，使用 Mac 硬體編碼（VideoToolbox）；音訊可沿用即
沿用。這以些許畫質換取遠快於軟體編碼的處理時間，並讓成品在不支援字幕軌的播放器
與平台也能顯示字幕。改字幕需重新輸出整支影片。

曾考慮的替代方案：只提供可切換字幕軌（多數手機相簿與社群平台看不到字幕）、
x264 軟體編碼（畫質較好但慢數倍）、讓使用者每次選快速／高畫質（增加選項）。

畫質選擇同時簡化為只選解析度：燒錄成品取該解析度畫質最佳的來源版本；可切換字幕軌
成品優先 H.264＋AAC 以確保 MP4 與瀏覽器直接播放，fps 自動取最高。

來源：2026-10-04 一鍵字幕成品訪談（Q1–Q18）。
